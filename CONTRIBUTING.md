# Contributing · 贡献指南

Thanks for helping improve this library. 感谢你帮助完善这个技能库。

## What helps most · 最有价值的贡献

- Real-world rules with numbers (budgets, thresholds, timelines) that worked for you
- Worked examples and templates for a reference file
- Fixes for outdated platform details (features and policies change often)
- Better Chinese translations in `SKILL.zh.md`

- 带具体数字的实战规则（预算、阈值、节奏）
- 参考文件里的完整示例和模板
- 修正过时的平台信息
- 改进 `SKILL.zh.md` 的中文表达

## How to contribute · 如何贡献

1. Fork the repo and create a branch.
2. Edit or add files following [AGENTS.md](./AGENTS.md).
3. Run `bash scripts/validate-skills.sh`.
4. Open a pull request describing what changed and why.

## Rules · 规则

- Original writing only; don't paste content from other repos, courses or paid materials.
- No real customer data, credentials or private account details.
- No tactics that break platform rules or laws (cloaking, account farming, fake reviews, spam).

- 只接受原创内容，不要粘贴其他仓库、课程或付费资料
- 不包含真实客户数据、账号凭据或隐私信息
- 不接受违反平台规则或法律的打法（伪装页、养号、刷评、垃圾邮件）
