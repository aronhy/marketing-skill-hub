# 广告开户与账户基础

> For agents: use when the user asks how to open or set up Meta, Google or TikTok ad accounts, what documents they need, agency accounts vs self-serve, spending limits, or permissions. Describe official routes only. Never help buy, rent or borrow accounts or identity documents. Platform requirements change; tell the user to confirm on the platform's official pages or with an official partner.

## 两条正规开户路线

| | 自助开户 | 通过官方授权代理商开户 |
|---|---|---|
| 怎么开 | 在平台官网用企业资料自己注册 | 联系平台官方公布的授权代理商，由代理商协助开户 |
| 适合 | 预算不大、想先试试 | 中国大陆企业、预算较大、需要人工支持 |
| 好处 | 快、免费、完全自己掌控 | 审核和充值流程清楚，常有更高的消耗额度和中文支持 |
| 注意 | 新账户有消耗限额，要慢慢提升；资料不一致容易被审核卡住 | 只找平台官网或官方渠道能查到的代理商；账户归属、费用、能否转出要在合同里写清 |

**判断标准很简单：** 账户必须用你自己公司的真实资料开，管理员是你自己的人。买号、租号、借别人的营业执照开户，都违反平台规则，被封后钱和数据都追不回来。

## 开户前准备好这些

| 准备项 | 说明 |
|---|---|
| 营业执照 | 中国大陆或香港公司都可以，信息要和后面填写的一致 |
| 法人或负责人身份证明 | 部分验证环节会用到 |
| 网站 | 能正常打开，有隐私政策、服务条款、退款政策、配送政策、联系方式和关于我们（见 `growth-strategy` → `references/landing-page.md`） |
| 推广域名 | 准备在 Meta 验证域名 |
| 企业邮箱 | 用公司域名的邮箱注册，不要用个人邮箱 |
| 付款方式 | 公司名下、平台支持的信用卡或充值方式 |
| 追踪 | 像素和服务器端回传先装好（见 `tracking-setup.md`） |
| 网络和设备 | 固定的公司网络，见 `network-environment`（如果你的仓库已安装） |

## Meta（Facebook 和 Instagram）

1. **建商务资产组合**（Business portfolio，原来叫商务管理平台）：在 business.facebook.com 用真实的个人账号创建，填写公司资料
2. **建 Facebook 主页**：广告要以主页的名义投放；同时关联 Instagram 专业账号
3. **建广告账户**：时区和币种选好，创建后一般不能改。时区通常选目标市场的时区，方便看每天的数据
4. **企业验证**：上传营业执照等资料，完成后账户更稳定、功能更全
5. **验证域名、装像素和转化 API**
6. **添加付款方式**
7. **分配权限**：每个员工用自己的账号加入，按需要给「管理」或「仅查看」权限；所有管理员开双重验证
8. **至少两个管理员**：防止唯一的管理员账号出问题后，整个商务资产被锁住

**新账户提示：** 新广告账户有每日消耗限额，正常消耗、按时付款后会逐步提高。第一周别急着大幅加预算。

## Google Ads

1. 在 ads.google.com 注册，选择专家模式（Expert mode），不要用默认的简易模式，否则很多设置看不到
2. 设置结算信息和付款方式
3. **广告主验证**：Google 会要求完成身份和业务验证，按提示提交营业执照等资料，没完成可能导致广告暂停
4. 安装 Google 代码和增强型转化，关联 GA4
5. 做购物广告的，同时开 **Merchant Center**，上传商品数据，补齐网站的配送和退货政策
6. 通过「访问权限和安全」给团队成员分配权限

## TikTok

1. 在 TikTok for Business 注册广告账户，填写企业资料，上传营业执照
2. 审核通过后添加付款方式
3. 建 **Business Center**，用来统一管理广告账户、TikTok 账号和成员权限
4. 安装 TikTok 像素和 Events API
5. 做 Spark Ads 的，提前把要投放的 TikTok 账号授权进来
6. 中国大陆企业常见做法是通过 TikTok 官方授权代理商开户，具体以 TikTok 官方渠道公布的为准

## 开户后第一周

- 先跑一个简单的广告系列，预算保守，按 `meta-ads.md` 的新账户节奏慢慢加
- 确认付款成功、没有政策提醒
- 下一笔真实测试订单，确认转化数据回传正常
- 记录好所有登录信息和管理员名单，放在公司安全的地方

## 账户结构建议

| 层级 | 建议 |
|---|---|
| 商务资产组合 | 一家公司一个，挂在公司真实资料下 |
| 广告账户 | 起步一个就够；不同品牌、不同币种或不同代理商再分开 |
| 主页 / 账号 | 一个品牌一个，名称和网站一致 |
| 像素 | 一个网站一个，不要多个网站共用 |

## 常见问题

**开户被拒或资料审核不通过怎么办？** 看清原因，常见是资料不一致（公司名、地址、网站对不上）或网站缺少政策页面。改正后重新提交，不要换一套资料重开。

**能不能一次开很多个广告账户？** 先用好一个。账户数量不会让广告效果变好，反而让管理和风控更复杂。

**代理商开的户归谁？** 一定要问清楚并写进合同：账户归属、充值和服务费、能否转出、终止合作后数据和账户怎么处理。
