# 其他平台：Facebook、Pinterest、X、Reddit、LinkedIn

> For agents: use when the user asks which platform to pick or about Facebook, Pinterest, X, Reddit or LinkedIn organic. Community and platform rules change; tell the user to check current rules.

## 先选平台

新手同时做的平台**最多两三个**。按产品和人群选：

| 平台 | 适合 | 主要用户 | 一句话打法 |
|---|---|---|---|
| TikTok | 能演示的产品、年轻人群 | 偏年轻 | 冲突开头的短视频，见 `tiktok.md` |
| Instagram | 视觉好看、生活方式品类 | 年轻到中年 | Reels 拉新 + 私信成交，见 `instagram.md` |
| YouTube | 要讲清楚、要被搜到的产品 | 全年龄 | Shorts 测题 + 长视频吃搜索，见 `youtube.md` |
| Facebook | 年龄偏大的人群、社群类 | 偏中年及以上 | 主页 + 群组，主要配合广告 |
| Pinterest | 家居、婚礼、美食、时尚、DIY | 以女性为主，有计划的购物者 | 竖图 + 关键词，像搜索引擎 |
| X | 科技、AI、B2B、创始人个人品牌 | 从业者、科技圈 | 观点和串推，建立个人影响力 |
| Reddit | 小众爱好、需要真实口碑的品类 | 很反感广告 | 先当真实用户参与，绝不硬广 |
| LinkedIn | B2B、外贸、服务 | 职场人士、采购决策者 | 创始人账号分享行业经验 |

## Facebook

- **主页**：开 Facebook 主页是投 Meta 广告的前提，信息要填完整，和网站一致
- **自然触达**：品牌主页的自然流量普遍有限，主要价值是配合广告、承接评论和私信
- **群组**：围绕兴趣建群（比如宠物主交流群），比主页发帖更有粘性
- **人群**：比 Instagram 和 TikTok 偏年长，适合面向中老年人群的产品

## Pinterest

- **本质是视觉搜索引擎**：用户来找灵感和要买的东西，一张图能被持续搜到很久
- **账号**：开商业账号，认领网站，开启商品目录（以当前资格为准）
- **内容**：竖图（2:3 比例常见），图上加简短文字，链接到具体商品页或文章
- **关键词**：标题、描述、画板名都写用户会搜的词
- **节奏**：持续稳定发，比偶尔爆发好

## X（Twitter）

- **适合**：科技、AI、B2B、创始人个人品牌，不太适合大众消费品直接卖货
- **打法**：观点、经验、串推（thread），持续输出某一个领域
- **个人账号通常比品牌账号更有效**
- **引流**：主页链接和置顶帖引导到周报或网站

## Reddit

- **用户很反感广告和营销**，硬广会被踩、被删、被封号
- **正确做法**：先作为真实用户参与相关社区，回答问题、提供帮助；在规则允许的情况下，以明确身份分享
- **一定要先读每个社区（subreddit）的规则**，很多社区禁止自我推广
- **价值**：Reddit 讨论常出现在 Google 搜索结果里，也是研究用户真实抱怨的好地方（见 `growth-strategy` → `references/competitor-ad-research.md`）
- 绝不用小号自问自答、刷赞

## LinkedIn

- **适合**：B2B、外贸工厂、服务型业务
- **创始人或业务负责人的个人账号**比公司主页更容易被看到
- **内容**：行业经验、客户案例（经授权）、工厂和生产过程、对行业趋势的看法
- **配合**：和 `cold-outreach` 的开发信一起用，对方查你时能看到专业形象

## 新手常见错误

- 所有平台一起开，每个都做不好
- 同一条内容不改格式就到处发
- 在 Reddit 和小众社区发硬广
- 各平台名字、头像、简介不统一，看起来不专业
