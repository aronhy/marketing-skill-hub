# 各运营场景的网络要求

> For agents: reference for the `network-environment` skill. Explain mechanics and compliant setups only.

## 广告后台（Meta、Google、TikTok 投放）

- **固定网络**：用公司的固定网络和固定出口 IP 登录，团队成员也尽量在这个网络里操作
- **一人一个账号**：每个人用自己的账号登录，通过商务管理平台分配权限，不要多人共用一个账号密码
- **双重验证**：所有管理员都开启
- **不要远距离跳登**：不要今天在公司登、明天换节点从另一个国家登
- **资料一致**：企业名称、地址、网站、付款卡在各处一致
- **从中国投放是允许的**：主流广告平台都接受中国广告主，可以用企业资料直接开户，或通过平台官方授权代理商开户。不需要也不应该伪装成美国广告主
- **遇到身份验证**：按平台提示完成验证，提供真实资料，不要换 IP 反复尝试

## 店铺后台（Shopify、亚马逊卖家中心）

- **Shopify**：后台本身对登录地限制较少，但支付渠道（如 PayPal、Shopify Payments）的风控很看资料一致性。员工用 Shopify 自带的员工账号功能，不要共享店主账号
- **亚马逊**：对「账号关联」特别敏感。亚马逊原则上要求每个卖家在每个站点只运营一个账号，除非有合理的业务需要并按规定申请，以亚马逊当前政策为准。多个店铺之间如果共用设备、网络、付款方式、地址、联系方式，可能被认定为关联，进而一起受影响。多店铺应当是合法独立的主体、合规申请
- **都不要用共享节点登录店铺后台**：店铺和资金都在里面，账号被锁的损失最大

## 社媒账号（TikTok、Instagram、YouTube 等）

- **少量账号、固定环境**：一套固定的设备和网络运营少量账号，不要一台手机挂一堆号
- **新号先正常使用**：先完善资料、正常浏览和互动几天，再开始发内容；注册当天就大量关注、私信、发帖，容易被限流
- **多人运营用官方工具**：Meta Business Suite、TikTok Business Center、YouTube 频道权限，都可以给团队成员分配权限，不需要共享密码
- **团队在国内、目标用户在美国**：平台会综合判断账号所在地。正规做法是用合规主体开商业账号、和美国本地的达人或团队合作发内容（见 `social-media`、`ugc-video`）。用代理伪装所在地属于规避平台规则，不在本文范围

## 冷邮件发信

邮件的世界里，IP 信誉直接决定邮件进收件箱还是垃圾箱。

- **用正规邮件服务商**：大多数卖家用服务商的发信 IP 就够了，服务商会维护 IP 信誉
- **共享 IP 和独享 IP**：共享 IP 池由服务商统一维护，适合中小发信量；独享 IP 只有发信量大且稳定时才需要，而且要预热
- **不要用机房服务器自己搭发信**：机房 IP 很多在黑名单里，冷邮件几乎必进垃圾箱
- **配合域名认证**：SPF、DKIM、DMARC 一个都不能少，见 `cold-outreach`

## 网站服务器

网站托管在机房 IP 上是正常的，不需要住宅 IP。用正规的建站平台或云服务，配合 CDN 加速，美国用户访问更快。
