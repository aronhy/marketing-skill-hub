# 出海营销术语表 · Glossary

给新手的中英对照表：每个词一句话说清楚。核心指标配同一个算例，方便对照着理解。

> For agents: when the user seems new, or uses or asks about a term listed here, explain it in plain words the first time it appears, in the user's language, using these definitions.

---

## 一个算例，串起所有核心指标

假设你卖一款售价约 48 美元的产品，**毛利率 60%**，跑了一周 Meta 广告：

| 原始数据 | 数值 |
|---|---|
| 广告花费 | $1,000 |
| 展示次数 | 50,000 |
| 覆盖人数 | 20,000 |
| 3 秒播放次数 | 15,000 |
| 链接点击 | 750 |
| 加购 | 75 |
| 购买 | 25 单 |
| 广告带来的收入 | $1,200 |
| 店铺当周总收入（含自然流量、老客） | $1,800 |

用这组数据，下面每个指标都能算出来：

| 指标 | 怎么算 | 结果 | 说明 |
|---|---|---|---|
| CPM | 花费 ÷ 展示 × 1000 | $20 | 每 1000 次展示花 20 美元 |
| CTR | 点击 ÷ 展示 | 1.5% | 每 100 个看到的人里有 1.5 个点进来 |
| CPC | 花费 ÷ 点击 | $1.33 | 每个点击 1.33 美元 |
| CVR | 购买 ÷ 点击 | 3.3% | 每 100 个点进来的人里有 3.3 个下单 |
| CPA | 花费 ÷ 购买 | $40 | 每拿到一单花 40 美元 |
| AOV | 收入 ÷ 订单数 | $48 | 平均每单 48 美元 |
| ROAS | 广告收入 ÷ 花费 | 1.2 | 每花 1 美元广告费，收回 1.2 美元 |
| 保本 ROAS | 1 ÷ 毛利率 | 1.67 | ROAS 要到 1.67 才不亏 |
| 保本 CPA | 每单毛利 = AOV × 毛利率 | $28.8 | CPA 要低于 28.8 美元才不亏 |
| MER | 店铺总收入 ÷ 总广告花费 | 1.8 | 看整体，不只看平台报的数 |
| 频次 Frequency | 展示 ÷ 覆盖人数 | 2.5 | 平均每人看到 2.5 次 |
| 钩子率 Hook rate | 3 秒播放 ÷ 展示 | 30% | 视频开头留住了 30% 的人 |

**结论：** CPA 40 美元高于保本线 28.8 美元，ROAS 1.2 低于保本线 1.67，这一周每单亏约 11 美元，合计亏约 280 美元（25 单 × 28.8 美元毛利 − 1000 美元花费）。

**拆解 CPA：** CPA ≈ CPM ÷（CTR × CVR）÷ 1000 = 20 ÷（1.5% × 3.3%）÷ 1000 ≈ 40。想降 CPA，就看是 CPM 太贵、CTR 太低，还是 CVR 太低，先修最差的那一个。

## 核心指标

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| CPM | Cost per mille | 每 1000 次展示的花费，反映流量贵不贵 |
| CPC | Cost per click | 每次点击的花费 |
| CTR | Click-through rate | 点击率，看到广告的人里点进来的比例，反映素材吸不吸引人 |
| CVR | Conversion rate | 转化率，点进来的人里下单的比例，反映页面和报价好不好 |
| CPA | Cost per acquisition | 每拿到一个转化（通常是一单）的广告花费 |
| AOV | Average order value | 客单价，平均每单金额 |
| ROAS | Return on ad spend | 广告支出回报，广告带来的收入 ÷ 广告花费 |
| 保本 ROAS | Break-even ROAS | 不赚不亏的 ROAS，等于 1 ÷ 毛利率 |
| 保本 CPA | Break-even CPA | 不赚不亏的 CPA，等于每单毛利 |
| 目标 CPA | Target CPA | 你愿意为一单付的最高广告费，一般低于保本 CPA，留出利润 |
| MER | Marketing efficiency ratio | 营销效率，店铺总收入 ÷ 总广告花费，比单个平台的 ROAS 更接近真实 |
| 毛利率 | Gross margin | 扣掉产品、运费、手续费、退货后剩下的比例 |
| LTV | Lifetime value | 一个客户一生会带来的总收入或总毛利，复购高的产品看这个 |
| 频次 | Frequency | 平均每人看到广告的次数，太高说明人群看腻了 |
| 钩子率 | Hook rate / thumb-stop rate | 视频前 3 秒留住人的比例 |
| 留存率 | Hold rate | 看完开头后继续往下看的比例，反映视频中段好不好 |

## 广告平台

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| 广告系列 / 广告组 / 广告 | Campaign / Ad set / Ad | Meta 广告的三层结构：系列定目标，组定预算和人群，广告是具体素材 |
| ABO | Ad set budget optimization | 预算设在广告组上，每组花多少你说了算，适合测试素材 |
| CBO | Campaign budget optimization | 预算设在系列上，由系统分给表现好的组，适合放量 |
| 进阶赋能型 | Advantage+ | Meta 的自动化广告，人群和版位大多交给系统 |
| 学习期 | Learning phase | 新广告组或大改动后，系统摸索谁会买的阶段，表现会波动 |
| 宽泛定向 | Broad targeting | 只限国家、年龄等，不加兴趣，让系统根据素材找人 |
| 相似受众 | Lookalike audience | 系统找跟你现有客户相似的人 |
| 再营销 | Retargeting | 对来过网站、加过购但没买的人再投广告 |
| 素材疲劳 | Creative fatigue | 同一素材投久了，CTR 下降、频次上升、成本变高 |
| 垂直放量 / 水平放量 | Vertical / horizontal scaling | 垂直是给赢家加预算，水平是复制赢家或推新角度 |
| 搜索广告 | Search ads | Google 上用户搜关键词时出现的文字广告 |
| 购物广告 | Shopping ads | Google 上带图片和价格的商品广告 |
| PMax | Performance Max | Google 的全自动广告，一个系列投到搜索、购物、YouTube 等所有位置 |
| Merchant Center | Google Merchant Center | 上传商品数据给 Google 购物广告用的后台 |
| RSA | Responsive search ad | 自适应搜索广告，你给多条标题和描述，Google 自动组合 |
| 匹配方式 | Match type | 关键词和搜索词怎么匹配：广泛、词组、完全匹配，越往后越精准 |
| 否定关键词 | Negative keywords | 告诉 Google 哪些搜索词不要展示你的广告，比如 free |
| 智能出价 | Smart bidding | 由系统自动出价，如目标 CPA（tCPA）、目标 ROAS（tROAS） |
| Spark Ads | Spark Ads | TikTok 用真实账号的自然帖子投广告，保留点赞评论 |
| UGC | User-generated content | 真人拍的、像普通用户分享的内容，广告里常用 |
| 落地页 | Landing page | 用户点广告后打开的那个页面 |

## 追踪与数据

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| 像素 | Pixel | 装在网站上的一段代码，告诉广告平台谁看了、谁买了 |
| CAPI | Conversions API | Meta 的转化 API，从服务器直接把订单数据发给 Meta，比像素更稳 |
| Events API | TikTok Events API | TikTok 版的服务器端转化回传 |
| 增强型转化 | Enhanced conversions | Google 用加密的邮箱等信息提高转化追踪准确度 |
| 事件去重 | Deduplication | 像素和服务器同时上报同一单时只算一次，避免重复计数 |
| GA4 | Google Analytics 4 | Google 的网站分析工具，用来交叉核对广告数据 |
| UTM | UTM parameters | 加在链接后面的标签，标明流量来自哪个渠道、哪条广告 |
| 归因 | Attribution | 一单算在哪个广告头上；各平台都会抢功劳，所以平台数加起来常常多于真实订单 |

## 邮件与冷邮件

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| SPF | Sender Policy Framework | 一条 DNS 记录，声明哪些服务器可以用你的域名发信 |
| DKIM | DomainKeys Identified Mail | 给每封邮件加数字签名，证明没被篡改、确实是你发的 |
| DMARC | DMARC | 告诉收件方，SPF 和 DKIM 不通过的邮件该怎么处理 |
| 预热 | Warm-up | 新邮箱先少量发信、慢慢加量，建立信誉，避免进垃圾箱 |
| 送达率 | Deliverability | 邮件进收件箱（而不是垃圾箱）的能力 |
| 退信率 | Bounce rate | 发不出去被退回的比例，太高会伤信誉 |
| 投诉率 | Spam complaint rate | 被收件人标记为垃圾邮件的比例 |
| CAN-SPAM | CAN-SPAM Act | 美国反垃圾邮件法，要求真实发件人、实体地址和退订方式 |
| 开发信 | Cold email / outreach | 主动发给潜在客户的第一封邮件 |
| 自动化流程 | Flow | 按触发条件自动发的一组邮件，如欢迎、弃单、购后 |
| 弃单 / 弃购 | Abandoned checkout / cart | 开始结账或加购后没付款 |

## 电商与履约

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| DTC / 独立站 | Direct-to-consumer | 用自己的网站（如 Shopify）直接卖给消费者 |
| 海外仓 / 第三方仓 | 3PL | 把货提前放在美国仓库，由仓库负责发货 |
| FBA | Fulfillment by Amazon | 货放进亚马逊仓，亚马逊负责配送和售后 |
| FBM | Fulfillment by Merchant | 在亚马逊上卖，但卖家自己发货 |
| MCF | Multi-Channel Fulfillment | 用 FBA 仓里的库存给独立站等其他渠道发货 |
| 起订量 | MOQ (minimum order quantity) | B2B 一次最少要订的数量 |
| FOB / DDP | Incoterms | 贸易术语：FOB 是货交上船就算交付，DDP 是卖家负责送到并交完关税 |
| HTS 编码 | HTS code | 美国海关商品编码，决定关税税率 |
| 拒付 | Chargeback | 买家通过发卡行撤回付款，太多会影响收款账户 |
| WISMO | Where is my order | 「我的订单在哪」类询问，配送慢时会大量出现 |

## 私域与成交

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| 线索 | Lead | 表达了兴趣、留下联系方式的潜在客户 |
| CRM | Customer relationship management | 记录和跟进客户的系统，起步用表格就够 |
| 点击即聊广告 | Click-to-message ads | 点广告直接打开 WhatsApp、Messenger 或 Instagram 私信 |
| 客服窗口 | Customer service window | WhatsApp Business 在客户最后一条消息后的一段时间（通常 24 小时）内可以自由回复，之后需用模板消息，以官方最新规则为准 |
| 话术 | Chat scripts | 聊天时可复用的回复模板 |

平台功能和规则经常变化，具体以各平台官方文档为准。
