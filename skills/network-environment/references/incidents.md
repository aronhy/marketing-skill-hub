# 出问题了怎么处理

> For agents: reference for the `network-environment` skill. Explain mechanics and compliant setups only.

| 情况 | 怎么处理 |
|---|---|
| 登录时要求验证 | 按提示完成验证（短信、邮箱、身份证件）。之后固定网络和设备，不要立刻换 IP 再试 |
| 账号被锁定 | 走平台官方申诉，提供真实的身份和企业资料。准备好营业执照、付款凭证、网站等材料 |
| 广告账户因异常登录被限制 | 检查最近有没有人从陌生地点或网络登录，修改密码、检查管理员列表、开双重验证，再申诉 |
| 发信 IP 或域名上了黑名单 | 立刻暂停发信，查原因（名单质量差、投诉率高），整改后按该黑名单的流程申请移除 |
| 公司网络 IP 被标记 | 联系网络服务商确认，必要时更换线路；不要临时改用共享节点 |

**平时就做好准备：** 账号资料保持真实一致，保存好营业执照、付款凭证、采购发票，出问题时申诉才有材料。
