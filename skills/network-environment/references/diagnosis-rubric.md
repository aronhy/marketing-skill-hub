# 诊断规则与报告模板

> For agents: the scoring rules for the `network-environment` skill. Apply them to the user's check results and setup answers, then fill the report template. When a field is missing, mark it 未知 and ask for it only if it changes a verdict.

## 第 1 步：从检测结果里读出 5 项

用户发来 ping123.app（或其他 IP 检测工具）的截图或文字结果，读出：

| 项目 | 记录为 | 在截图里找 |
|---|---|---|
| IP 类型 | 住宅 / 静态住宅（ISP）/ 机房 / 移动 / 未知 | 「IP 类型」「住宅」「原生」「数据中心」等字样 |
| ASN / 运营商 | 名称 | ASN、ISP、组织 |
| 地理位置 | 国家、州或城市 | 位置、地区 |
| 代理 / VPN 标记 | 是 / 否 | 代理、VPN、Tor 检测 |
| 黑名单 | 命中数量 | 黑名单、风险评分 |

读不清的项目标「未知」，不要猜。

## 第 2 步：问清使用情况

| 问题 | 为什么要问 |
|---|---|
| 这个网络用来做什么（广告后台 / 店铺后台 / 社媒账号 / 发邮件） | 不同场景标准不同 |
| 网络是怎么来的（公司宽带、企业跨境专线、家庭宽带、手机热点、云服务器、购买的代理、共享 VPN 节点） | 决定稳定性和合规性 |
| IP 多久变一次 | 判断一致性 |
| 多少人、多少个账号在用这个网络和设备 | 判断共用和关联风险 |
| 账号平时从哪里登录 | 判断位置一致性 |
| 最近有没有遇到验证、锁号、限流、邮件进垃圾箱 | 判断是否需要走处理流程 |
| 账号是否都开了双重验证、是否多人共用一个登录 | 判断账号安全 |

## 第 3 步：按场景判定

每个场景给一个结论：**适合 / 有风险 / 不适合**。命中任意一条「不适合」就判不适合；没有「不适合」但命中「有风险」就判有风险。

### 广告后台、店铺后台

| 结论 | 条件 |
|---|---|
| 不适合 | 共享 VPN 节点；被标记为代理或 VPN；命中黑名单；IP 经常变化或经常切换节点；多人共用一个登录账号 |
| 有风险 | 家庭宽带或手机网络（IP 会变）；登录地和账号平时的登录地不一致；同一网络下运营多个亚马逊店铺；没开双重验证 |
| 适合 | 企业跨境专线或固定的公司网络；未被标记；无黑名单；登录地一致；一人一个账号并开了双重验证 |

### 社媒账号

| 结论 | 条件 |
|---|---|
| 不适合 | 共享 VPN 节点；一个 IP 或一台设备上挂了大量账号；命中黑名单；频繁切换节点 |
| 有风险 | 被标记为代理或 VPN；一套环境运营的账号较多；新号注册后马上大量操作 |
| 适合 | 固定网络和固定设备，运营少量账号；多人协作用平台官方的团队权限 |

### 冷邮件发信

先确认：发信用的是**邮件服务商的发信 IP**，不是办公网络的 IP。检测对象是发信 IP 和发信域名。

| 结论 | 条件 |
|---|---|
| 不适合 | 用机房服务器自己搭发信；发信 IP 或域名命中主流黑名单 |
| 有风险 | 刚换独享 IP 还没预热；Google Postmaster Tools 显示信誉偏低 |
| 适合 | 正规邮件服务商发信；无黑名单；SPF、DKIM、DMARC 齐全 |

### 网站服务器

机房 IP 是正常的，不按「住宅」标准判断。只看：是否命中黑名单、美国用户访问速度是否正常。

### 超出范围的情况

如果用户的网络是用来**伪装成另一个国家的用户**（比如人在国内，用购买的海外代理冒充当地用户，去规避平台的地区限制），不要评估「伪装得好不好、会不会被识别」。用一两句话说明这属于规避平台规则、被识别后账号和资金都有风险，然后给出正规路径：合规主体开户、企业跨境专线、和当地达人或团队合作（见 `scenarios.md`）。

## 示例

用户情况：深圳 5 人团队，用公司宽带登录 Meta 广告后台；另外有人用手机连共享 VPN 节点登录同一个广告账户；最近两次登录被要求身份验证。ping123 显示：住宅 IP，中国，未标记代理，无黑名单。

```
## 网络环境诊断

**一句话结论：** 公司宽带适合登录广告后台；问题出在有人用共享 VPN 节点登录同一个账户，这很可能就是最近频繁要求验证的原因。

### 场景判定
| 场景 | 结论 | 原因 |
|---|---|---|
| 广告后台（公司宽带） | 适合 | 固定网络、未标记、无黑名单 |
| 广告后台（手机 + 共享节点） | 不适合 | 共享节点、IP 频繁变化、登录地和公司不一致 |

### 现在就做
1. 停止用共享节点登录广告账户，所有人统一在公司网络操作
2. 检查商务管理平台的管理员列表，移除不认识的人，所有人开双重验证
3. 下次出现验证时，在公司网络按提示完成，不要换网络重试

### 长期建议
- 如需更稳定的跨境访问，以企业身份向有资质的运营商咨询跨境专线
- 每人一个账号，通过商务管理平台分配权限
```
