# YouTube 运营

> For agents: use for organic YouTube (Shorts and long-form). For YouTube ads see `paid-ads` → `references/google-ads.md` (Demand Gen / video). Features and limits change often; tell the user to confirm current rules in YouTube Studio.

## 适合谁

需要讲清楚、要被搜到的产品和品牌：教程类、测评类、B2B、高客单价、需要比较和决策的产品。YouTube 是搜索引擎，一条好视频能被持续搜到很多年，是寿命最长的内容平台。

## 两种内容，两种打法

| | Shorts（短视频） | 长视频 |
|---|---|---|
| 时长 | 短，竖屏 | 几分钟到几十分钟，横屏 |
| 流量来源 | Shorts 推荐流 | 搜索、推荐、订阅 |
| 作用 | 快速触达、测试选题 | 建立信任、长期搜索流量、促成购买 |
| 投入 | 低，可复用 TikTok / Reels 素材 | 高，需要脚本、录制、剪辑 |
| 新手建议 | 先从这里开始 | 每 1 到 2 周一条，或先不做 |

## 频道设置

- **频道名和 @handle**：和品牌一致
- **频道简介**：前两行写清楚频道讲什么、适合谁，带上关键词
- **频道横幅和头像**：品牌统一
- **链接**：放独立站、周报订阅等，加 UTM
- **频道预告片**：给新访客的一分钟介绍（可选）
- **播放列表**：按主题整理，比如「使用教程」「选购指南」「客户故事」

## 长视频：标题和缩略图最重要

在 YouTube 上，**有没有人点**决定了一切。
- **标题**：用户会搜的说法 + 一个点击理由，比如「Best Seat Cushion for Back Pain? I Tested 5 for 30 Days」（内容必须真实）
- **缩略图**：一张大脸或产品特写 + 不超过 3 到 4 个大字，手机上也看得清。缩略图和标题互补，不要重复同一句话
- **测试**：YouTube Studio 有缩略图和标题对比测试功能，可以测几个版本（以当前是否可用为准）

## 长视频的结构

1. **前 30 秒**：直接回答「这个视频能帮你什么」，不要长片头、不要「大家好欢迎来到我的频道」
2. **正文**：按章节讲，每个章节一个要点；在描述里加时间戳，生成章节
3. **证明**：演示、对比、数据，比口头说更有说服力
4. **行动号召**：订阅、看下一个视频、描述里的链接

## 关键词和描述

- 选题前先在 YouTube 搜索框输入关键词，看下拉推荐，这就是用户真实在搜的
- 标题、描述前两行、口播里都自然地包含关键词
- 描述里写：视频讲了什么、时间戳章节、相关链接
- 标签作用有限，不用花太多时间

## Shorts 要点

- 竖屏，开头就进入主题，没有铺垫
- 可以和 TikTok、Reels 共用素材，但用无水印的原始文件
- 用 Shorts 测选题：哪个主题表现好，就做成长视频深入讲

## 看哪些数据

| 指标 | 说明 | 不好时怎么改 |
|---|---|---|
| 缩略图点击率（CTR） | 有没有人点 | 改标题和缩略图 |
| 平均观看时长 / 观看百分比 | 能不能留住人 | 前 30 秒更直接，剪掉拖沓部分 |
| 观众留存曲线 | 哪一秒开始掉 | 找到掉的位置，下次避免 |
| 流量来源 | 搜索、推荐、外部 | 搜索少就加强关键词 |
| 订阅转化 | 观众愿不愿意继续看 | 结尾引导、做系列内容 |
| 链接点击 | 能不能带来生意 | 描述和口播都提到链接 |

## 不露脸也能做

- 录屏讲解、产品特写、手部演示加配音，都是常见形式
- 配音可以自己录，用好一点的麦克风，比画面精致更重要
- 剪辑工具：剪映、Descript 等

## 新手常见错误

- 片头太长，前 30 秒都在铺垫
- 标题写成「我的新视频」这种没人搜的词
- 缩略图字太小、太多
- 只更新几期就放弃。YouTube 起量慢，但积累的内容会持续带流量
- 用未授权的音乐和素材，可能被版权声明或下架
