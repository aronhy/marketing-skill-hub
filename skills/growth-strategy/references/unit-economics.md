# Unit Economics Reference

## Formulas

| Metric | Formula |
|---|---|
| Landed cost per unit | Product cost + inbound freight + duties/tariffs + packaging |
| Variable cost per order | Landed cost + fulfillment + last-mile shipping + payment fees + returns allowance |
| Gross profit per order | Price (+ shipping charged) − variable cost per order |
| Gross margin | Gross profit ÷ price |
| Break-even ROAS | 1 ÷ gross margin |
| Break-even CPA | Gross profit per order |
| Target CPA | Gross profit per order − desired profit per order |
| AOV | Revenue ÷ orders |
| MER | Total revenue ÷ total marketing spend |
| Payback on CPA (repeat products) | CPA ÷ gross profit per order per month of retention |

## Worked example (fictional CoreSeat cushion)

| Line | Amount |
|---|---|
| Price | $49.00 |
| Product cost (FOB) | $6.50 |
| Inbound freight + duties (per unit, estimate) | $2.50 |
| Fulfillment + last-mile shipping | $5.00 |
| Payment fees (~3%) | $1.50 |
| Returns allowance (~5% of price) | $2.50 |
| **Variable cost per order** | **$18.00** |
| **Gross profit per order** | **$31.00** |
| Gross margin | 63% |
| Break-even ROAS | 1.58 |
| Target CPA (keep $10) | $21 |

## Sanity checks

- Gross margin under ~50%: paid social will be hard on first orders. Raise AOV (bundles), raise price, or rely on repeat purchases with a known LTV.
- Shipping charged to the customer counts as revenue, but free shipping usually converts better in the US; model both.
- Tariff and de minimis rules change. Confirm current duty rates for the product's HTS code before trusting the landed cost.
- Add sales tax handling: in the US it is collected from the buyer and remitted, not part of margin, but the store must be set up for it where required.
