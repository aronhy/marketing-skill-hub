# 广告投放

> 中文阅读版。给 AI 执行的指令见同目录 `SKILL.md`，各部分详细内容见 `references/`。
## Meta 广告


### 目标

账户配置正确、结构适合测试和放量，用明确的规则管理，而不是凭感觉。

### 搭建清单

- 商务资产组合已验证，信息与网站和付款方式一致
- 域名已验证；像素 + 转化 API，事件已去重
- 网站具备隐私政策、退款政策、配送政策、联系页和关于我们
- 付款方式稳定；新账户先保守消耗
- 首次上线前阅读 `references/ad-policy-compliance.md`

### 账户结构

越简单越好，少而预算足的广告系列学习更快。

- **测试系列**：找赢家素材，宽泛定向，固定日预算
- **放量系列**：放已验证的赢家，用进阶赋能型（Advantage+）销售系列或 CBO
- **再营销**（可选，有足够流量后再做），注意避免预算重叠

默认宽泛定向 + 强素材。在 Meta 上，素材本身就在做定向。

### 预算规则

- 广告组每周约需 50 次优化事件才能退出学习期；预算不够就暂时优化更上层事件，或合并广告组
- 测试预算约占总消耗 20%

### 测试设置（常规默认值，按账户调整）

- 素材测试用 ABO，保证每个概念都有固定预算；放量用 CBO 或进阶赋能型系列
- 一个概念一个广告组，每组 3–5 条（同一概念的不同钩子或形式）
- 每个测试广告组日预算约 1 倍目标 CPA，2–3 天内能出结论
- 至少跑 3 天再按 CPA 判断，不要第一天就下结论

### 新素材关停 / 保留规则

| 情况（达到对应消耗后） | 决定 |
|---|---|
| 消耗约 1 倍目标 CPA，链接 CTR 明显低于账户平均，且无加购 | 关停 |
| 消耗约 1.5–2 倍目标 CPA，无购买 | 关停 |
| 消耗约 2 倍目标 CPA，有购买但 CPA 高于目标 20–50%，钩子率和 CTR 强 | 迭代：换钩子、换落地页，再跑几天 |
| 连续 3 天以上 CPA 达标且有多笔购买 | 赢家，移入放量 |

CTR 和钩子率以自己账户的平均值为基准，不要用网上的行业基准。

### 放量规则

- **垂直放量**：CPA 在目标内时，每 48–72 小时提预算约 20%；CPA 突增当天不加预算
- **水平放量**：垂直加预算开始推高 CPA 时，停止加，改为把赢家复制到新广告组或放量系列，或推同一赢家概念的新角度
- 一次加幅超过约 50%、或广告组仍在学习期时，优先复制而不是猛加预算

### 放量翻车怎么救

最常见：加预算太快太频繁，CPA 飙升、重新进入学习期。
1. 别慌着改，除非明显在浪费钱，先等 2–3 天
2. 预算回退到上一个 CPA 稳定的水平
3. 看频次和 CTR，素材疲劳就上新素材，而不是加预算
4. 放慢节奏继续放量，或改为水平放量

### 新账户起步

新账户信任度低，常见节奏：
- 第 1 周：小额日消耗（如每天几十美元），一个简单系列，广告和网站完全合规
- 第 2 周：无政策标记、付款正常时逐步增加（每几天约 20–30%）
- 前几周避免预算猛涨、同时开一堆新系列、频繁更换付款方式
- 有明确目标 CPA 和足够转化量时再用成本上限或竞价上限
- 不要大改正在跑好的广告组，大改可能重置学习期

### 排查：CPA 上涨

| 变化的指标 | 可能原因 | 怎么做 |
|---|---|---|
| CPM 上涨 | 季节性（Q4）、人群饱和、素材质量低 | 上新素材、放宽人群、接受季节性上涨 |
| CTR 下降、频次上升 | 素材疲劳 | 赢家概念换新钩子，或上新概念 |
| CTR 正常、转化率下降 | 落地页、报价、库存、网速、结账故障 | 检查网站和报价 |
| 数据看似正常但转化骤降 | 追踪坏了 | 检查事件管理工具 |
| 投放停止 | 政策标记、付款失败、消耗限额 | 见 `references/ad-policy-compliance.md` |

### 中国卖家常见误区

- 一堆小预算广告组，永远出不了学习期
- 弱素材叠加窄兴趣定向
- 投一天、花几美金就下结论
- 新账户一夜之间把预算拉满
- 一条素材跑几个月，疲劳了怪算法

### 输出格式

上线前需补的问题、广告系列结构表、上线清单、14 天计划与判断规则；若已在投，按排查表诊断并给出接下来三步。

平台功能和名称经常变动，给具体操作步骤时以广告管理工具当前界面为准。

## Google 广告


### 目标

用干净的转化追踪、合理的广告系列组合和每周优化流程，盈利地承接已有的搜索需求。

### 选择广告系列类型

| 情况 | 先做 |
|---|---|
| 电商且有商品数据 | 购物广告或效果最大化（PMax），前提是商品数据优化好 |
| 用户在搜问题或品类 | 非品牌词搜索广告 |
| 品牌已有搜索量 | 品牌词搜索广告（便宜，防竞品截流） |
| 需要曝光或素材触达 | 搜索跑通后再做需求开发（Demand Gen）或 YouTube |

### 搜索广告

1. 按意图做关键词：购买意图、问题意图、对比意图（X vs Y、X 替代品）
2. 按主题细分广告组，让广告和落地页与搜索词匹配
3. 匹配方式：广泛匹配只配合智能出价和充足否定词使用；小预算用词组和完全匹配控制流量
4. 第一天就加否定词：free、jobs、DIY、used 等
5. 自适应搜索广告：最多 15 个标题（30 字符）、4 条描述（90 字符），覆盖关键词、利益点、证明、报价、行动号召
6. 补全附加信息：附加链接、宣传信息、结构化摘要、图片

### 购物广告与 PMax

- 商品数据质量决定效果：标题写清品牌 + 产品 + 关键属性 + 尺寸颜色，有 GTIN 就填，图片清晰，价格库存准确
- Merchant Center 要求清晰的配送和退货政策、联系方式、可信网站，新出海店铺常因「虚假陈述」被封
- PMax 按品类或利润档分资产组，并加品牌排除

### 出价

- 先用尽可能提高转化（或转化价值）积累数据
- 30 天内约有 30 个以上转化后，再切目标 CPA 或目标 ROAS
- 每次调整 10–20%，两次调整间隔一周

### 每周优化

- 看搜索词报告：加否定词，表现好的词单独拿出来
- 看展示份额：是预算不足还是排名不足
- 消耗超过 2 倍目标 CPA 仍无转化的词和商品暂停
- 替换表现差的广告素材资产
- 对比各广告组的落地页转化率

### 中国卖家常见误区

- 广泛匹配 + 无否定词 + 手动出价
- 所有流量都导到首页
- 不重视 Merchant Center 政策，直到被封
- 让 PMax 吃品牌词流量，误以为是新增长

### 输出格式

广告系列组合与预算分配、关键词表、否定词清单、每个广告组 15 个标题和 4 条描述、商品数据修改建议、每周优化清单。

字符限制和广告系列选项会变，以 Google Ads 当前界面为准。

## TikTok 广告


### 目标

围绕持续供应的原生风格素材搭建 TikTok 投放，追踪可用，测试和更新有章法。

### 核心原则

- **素材就是策略**：广告要像 TikTok 内容，竖屏 9:16、真人对镜头说话、真实场景、字幕、有声
- **前 2–3 秒决定一切**：开头就上钩子，不要先放 logo
- **数量胜过精致**：每周要有多条新素材，TikTok 素材疲劳比 Meta 快，常在一两周内

### 投放搭建

- 从宽泛定向开始，让算法根据素材信号找买家
- 用自动化系列（如 Smart+）或简单结构：一个测试系列 + 一个放量系列
- 在当前界面确认广告组最低预算，预算不足出不了学习期
- **Spark Ads**：用自己账号或达人（需授权码）的自然帖子投广告，保留点赞评论，更原生
- 做 TikTok Shop 的，先把商品页、价格和评论做好，再用店铺专属系列

### 有效的素材形式

- 真人讲述：问题 → 解决方案
- 开箱与第一印象
- 「我换用 XX 的三个理由」
- 绿幕回应评论或差评
- 使用过程演示（避免政策敏感的前后对比）
- 回复评论视频，针对性消除顾虑

### 看哪些指标

- 钩子：2 秒和 6 秒播放率
- 留存：平均观看时长、完播率
- 点击：CTR
- 转化：CVR、CPA、ROAS

钩子率高但 CTR 低，说明中段或行动号召弱；钩子率低，就换开头。

### 经验法则

- 按计划定期换素材，不要等效果崩了再换
- 赢家视频保留主体，换五个钩子测试
- 广告只用 TikTok 商用音乐库里的音乐
- Spark Ads 的评论是公开的，要管理并回复顾虑

### 中国卖家常见误区

- 把电视广告风格或 Meta 图片素材直接搬上 TikTok
- 钩子太慢或以品牌开头
- 使用未获商用授权的热门音乐
- 文案翻译腔重，应找能自然对美国观众说话的达人

### 输出格式

投放计划、5 个素材创意（钩子、形式、要点）、每周素材生产与更新排期、素材保留 / 迭代 / 关停的指标阈值。

TikTok 广告产品和政策变化频繁，以 TikTok Ads Manager 当前界面为准。

## 追踪配置


### 目标

每个广告平台都收到准确的购买（或线索）事件，不重复计数，并有一个独立的数据来源用来核对平台数据。

### 追踪方案

| 平台 | 浏览器端 | 服务器端 | 重点检查 |
|---|---|---|---|
| Meta | 像素 | 转化 API | 浏览器和服务器事件用同一个 `event_id` 去重；事件匹配质量良好 |
| Google | Google 代码 | 增强型转化；如用 GA4 则导入转化 | 传递金额和币种；每个目标只设一个主要转化 |
| TikTok | TikTok 像素 | Events API | 用 `event_id` 去重；传递金额和币种 |
| 分析 | GA4 | — | 定义关键事件，关联广告平台 |

Shopify 等主流建站平台优先用各广告平台的官方集成或应用，服务器端事件和去重都能自动处理。

### 标准电商事件

浏览页面 → 查看商品 → 加购 → 发起结账 → 添加支付信息 → 购买（带金额、币种、商品 ID）。线索类：浏览 → 提交线索 / 注册 →（可能的话）回传合格线索。

### UTM 规范

- `utm_source`：平台（facebook、google、tiktok、newsletter）
- `utm_medium`：paid_social、cpc、email、influencer
- `utm_campaign`：广告系列名
- `utm_content`：广告或素材 ID

全部小写、用下划线。

### 校验

1. 下一笔真实测试订单（之后退款）或提交测试线索
2. 用各平台测试工具检查：Meta 事件管理工具、Google Tag Assistant、TikTok 像素助手
3. 确认金额币种正确、事件只触发一次
4. 对比同一周平台报告的购买数与实际订单数。平台通常因归因重叠而多报；如果反过来差很多，多半是追踪坏了

### 隐私

- 网站要有说明追踪行为的隐私政策
- 美国多个州有隐私法，要求为数据「出售」或「共享」提供退出选项；欧盟或英国流量需先取得同意
- 各州法律不同且在变化，具体要求请自行确认

### 输出格式

追踪方案表、事件及参数清单、UTM 规范、逐步校验清单、现存问题及修复办法。

## 广告合规与防封


### 目标

通过遵守平台规则，让广告和账户稳定运行；被标记时有冷静、基于事实的处理流程。

### 范围与红线

本技能帮助合规，不帮助规避审核。以下请求会被拒绝并说明原因：伪装页面（给审核看一个页面、给用户看另一个）、购买 / 租用 / 养号、冒用他人身份或营业资料、开新户绕过封禁。这些都违反平台条款，通常导致永久封禁。

### 上线前检查

**主体与账户**
- 广告账户、付款方式、网站上的公司信息一致
- 能做企业验证的都做
- 所有管理员开启双重验证
- 付款方式稳定，新账户逐步提高消耗

**网站**
- 产品信息清楚、价格真实、配送时间准确
- 隐私政策、条款、退款退货政策、配送政策、带真实邮箱的联系页
- 落地页与广告宣称和报价一致
- 无遮挡内容的弹窗，结账流程正常

**广告内容**
- 不做无法证实的宣称（「治愈」「保证效果」、无依据的「第一」）
- 不用「个人特征」语句（如「你超重吗？」「被债务困扰吗？」），讲产品而不是讲用户的特征
- 健康、减肥、美容类避免前后对比图
- 不用假按钮、假通知、误导性紧迫感
- 价格折扣真实，落地页可兑现
- 不擅用商标、名人、受版权保护的音乐和画面

### 高风险品类

保健品、减肥、带医疗宣称的化妆品、CBD、酒类、金融、交友、博彩、成人用品、武器相关等有额外规则、资质要求甚至完全禁止，各平台各国不同，投放前查看最新政策。

### 被标记后

1. 看清具体原因和对应政策
2. 确实违规就修改广告或落地页，不要原样重提
3. 误判就通过官方渠道申诉，简短陈述事实
4. 账户级限制先完成要求的验证并等待审核，不要另找捷径让情况更糟
5. 记录每次拒审的原因和修改，避免重犯

### 输出格式

逐项检查表（通过 / 需修改）、文案中的风险表述及合规改写、品类风险提示、被标记时的原因、修改方案和申诉文案草稿。

政策更新频繁，最终以平台当前的广告政策页面为准。
