# TikTok 自然流量运营

> For agents: use for organic TikTok (not paid ads; for ads see `paid-ads` → `references/tiktok-ads.md`). Platform features, limits and US availability change often; tell the user to confirm current rules in the app.

## 适合谁

产品能用视频演示、目标人群偏年轻、想低成本测试内容方向的品牌。TikTok 推荐不太看粉丝数，新账号的视频也有机会被推给很多人，是冷启动最快的平台之一。

## 账号设置

- **账号类型**：用商业账号（Business account）。可以看数据、挂链接、投 Spark Ads；代价是只能用商用音乐库里的音乐
- **用户名**：和品牌名一致，好拼写，各平台尽量统一
- **头像**：品牌 logo 或创始人头像，小尺寸下也看得清
- **简介**：一句话说清你是谁、帮谁解决什么问题，加一个行动号召
- **主页链接**：放独立站、落地页或链接聚合页，加 UTM
- **地区和语言**：账号面向美国用户，就用美国用户熟悉的英文内容

## 推荐机制（简化理解）

系统先把视频推给一小批人，看他们的反应，反应好就推给更多人。主要看：
- **完播率和观看时长**：有没有看完、有没有重看
- **互动**：分享、评论、收藏、点赞，其中分享和评论分量更重
- **相关性**：视频主题、字幕、文案、话题标签和用户兴趣是否匹配

所以最重要的是**前 3 秒留住人**，和**让人看完**。

## 内容形式

| 形式 | 适合 | 要点 |
|---|---|---|
| 真人口播 | 讲痛点、讲经验、回答问题 | 对着镜头说话，像跟朋友聊天 |
| 产品演示 | 效果直观的产品 | 特写、真实场景、一镜到底更可信 |
| 前后对比 / 测试 | 清洁、整理、修复类 | 不夸张，健康美容类避免夸大前后对比 |
| 回复评论视频 | 消除顾虑、制造互动 | 直接用评论做开头 |
| 幕后 / 创始人日常 | 建立信任和人设 | 工厂、打包、选品过程 |
| 教程 / 清单 | 收藏率高 | 「3 个方法」「5 个错误」 |
| 图文轮播（Photo mode） | 清单、对比、步骤 | 第一张图就是钩子 |

## 一条好视频的结构

1. **0–3 秒钩子**：要有冲突（问题当场出现、人和人的反差、预期和现实的反转）。见 `ugc-video`
2. **3–15 秒**：展开问题，给出看下去的理由
3. **中段**：演示、证明、干货，每隔几秒换一个画面或镜头
4. **结尾**：一个明确的动作（关注看下一条、评论区回答、主页链接）

时长：先从 15 到 45 秒做起，内容撑得住再做长。

## 发布节奏

- 新账号：每周 3 到 5 条，先求稳定，再求数量
- 同一个内容方向连续发，让系统知道你的账号是做什么的
- 发布后 1 小时内回复评论
- 发布时间按美国时区（东部、太平洋时间的早晚高峰都可以测）

## 搜索（TikTok SEO）

越来越多美国用户直接在 TikTok 上搜东西。
- 视频里**说出**关键词，屏幕文字和文案里也写上
- 话题标签 3 到 5 个：1 到 2 个大词、2 到 3 个精准词，不要堆
- 用你的产品要解决的问题做标题，比如「how to remove pet hair from couch」

## 音乐

商业账号只能用**商用音乐库**的音乐。不要用未授权的热门歌，可能被静音或下架，投成广告也会出问题。

## 看哪些数据

| 指标 | 说明 | 不好时怎么改 |
|---|---|---|
| 平均观看时长、完播率 | 视频能不能留住人 | 改开头、剪短、加快节奏 |
| 2 秒 / 6 秒留存 | 开头是否有效 | 换钩子 |
| 分享、收藏 | 内容有没有价值 | 多做教程、清单、干货 |
| 评论 | 有没有引发讨论 | 在视频里提问，用评论做续集 |
| 主页访问、链接点击 | 能不能带来生意 | 简介和链接更清楚，视频结尾引导 |
| 流量来源 | 推荐页、搜索、关注 | 搜索占比低就加强关键词 |

## 和广告、电商的衔接

- 表现好的自然视频，直接用 **Spark Ads** 投成广告（见 `paid-ads`）
- 做 TikTok Shop 的，视频可以挂商品，配合达人带货（见 `ugc-video`）
- 视频去掉水印后可以同步发到 Instagram Reels 和 YouTube Shorts

## 新手常见错误

- 一上来就发硬广，没人看
- 三天两头换内容方向
- 用电视广告式的精致视频，不像原生内容
- 看到几条没流量就放弃。前 20 到 30 条是在找方向
- 批量注册账号、买粉、刷互动：违反平台规则，账号会被限流或封禁
- 不回评论
