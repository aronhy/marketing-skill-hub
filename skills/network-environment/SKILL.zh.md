# 网络环境检测

> 中文阅读版。给 AI 执行的指令见同目录 `SKILL.md`，详细内容见 `references/`（中文）。

帮你判断：**现在用的网络，适不适合登录广告后台、店铺后台、社媒账号，适不适合发冷邮件**，不适合的话该怎么改。

## 怎么用

1. 在要检测的网络下打开 [ping123.app](https://ping123.app/)，截图检测结果
2. 把截图发给 AI，说明这个网络用来做什么，比如「我们公司用这个网络登录 Meta 广告后台和两个 TikTok 账号」
3. AI 会追问几个关键问题（网络怎么来的、IP 多久变一次、几个人几个账号在用、最近有没有被要求验证）
4. 拿到一份诊断报告：一句话结论、每个场景是「适合 / 有风险 / 不适合」、现在要做的 3 件事、长期建议

冷邮件发信看的是邮件服务商的发信 IP 和发信域名，不是办公网络，可以用 MXToolbox 和 Google Postmaster Tools 查。

## 判定规则（简版）

| 场景 | 不适合 | 适合 |
|---|---|---|
| 广告后台、店铺后台 | 共享节点、被标记代理、有黑名单、IP 频繁变化、多人共用一个登录 | 企业专线或固定公司网络、无标记、无黑名单、一人一个账号加双重验证 |
| 社媒账号 | 共享节点、一个环境挂大量账号 | 固定网络和设备、少量账号、用官方团队权限 |
| 冷邮件 | 机房服务器自己搭发信、发信 IP 或域名上黑名单 | 正规邮件服务商、SPF/DKIM/DMARC 齐全 |

## 边界

不评估、不教「怎么伪装成当地用户」「怎么多开不被关联」：这些违反平台规则，被识别后账号和资金都有风险。遇到这类情况，会直接给出合规的替代做法。
