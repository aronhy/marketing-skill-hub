# 多角度广告文案

> 中文阅读版。给 AI 执行的指令见同目录 `SKILL.md`。

## 目标

按不同角度和平台产出一套带标签、可直接测试、读起来像母语者写的广告文案。

## 用户认知阶段

按读者已知程度选择开头：

1. **无认知**：用故事、意外事实、熟悉的场景开头
2. **知道问题**：用他们的原话说出问题
3. **知道解决方案**：说明为什么这个方法比替代方案好
4. **知道产品**：证明、对比、报价
5. **高度认知**：只需报价和紧迫感

## 角度库

| 角度 | 核心 |
|---|---|
| 痛点 | 他们今天的烦恼 |
| 结果 | 问题解决后的生活 |
| 社会证明 | 其他用户怎么说、有多少人在用 |
| 权威 | 专家、认证、媒体、数据 |
| 对比 | 我们 vs 常规选择（不恶意点名竞品） |
| 消除顾虑 | 回答最主要的犹豫原因 |
| 演示 | 一句话讲清原理 |
| 故事 | 创始人或用户故事 |
| 身份认同 | 「为……的人设计」 |
| 价值 | 单次使用成本、省多少、组合装 |
| 风险逆转 | 保障、免费退货、试用 |
| 好奇 | 让人停下来的意外说法 |
| 真实紧迫感 | 只用真实的截止日期或库存 |

长文案结构：PAS（问题、放大、解决）、BAB（之前、之后、桥梁）、AIDA。

## 平台格式

- **Meta**：主文案前约 125 字符会在「查看更多」之前显示，钩子放这里；标题约 40 字符
- **Google 自适应搜索广告**：标题最多 30 字符，描述最多 90 字符，每个标题要能单独成立
- **TikTok**：广告文字要短，真正的钩子在视频前几秒和屏幕字幕上

## 写出地道英文

- 口语化、用 you、短句、用缩写（you'll、it's）
- 具体胜过笼统：「10 分钟就干」胜过「速干」
- 避免翻译腔：high quality、best choice、Dear customer、Our company is professional、形容词堆砌、乱用大写、满屏感叹号
- 避免政策风险：不问个人特征问题、不用无法证明的最高级

## 流程

1. 确认产品事实和证明，绝不编造数据、评论或宣称
2. 按认知阶段选 5–8 个最相关的角度
3. 每个角度写 3 个钩子，再为最好的那个写各平台完整文案
4. 每条文案打标签，方便测试结果回溯到角度
5. 标出需要用户核实的宣称

## 输出格式

表格：编号、角度、认知阶段、平台、钩子、正文 / 描述、标题、行动号召、待核实宣称。最后说明优先测试哪 3 条及原因。
