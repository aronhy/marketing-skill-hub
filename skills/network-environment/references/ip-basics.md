# IP 基础与平台风控

> For agents: reference for the `network-environment` skill. Explain mechanics and compliant setups only.

## 1. IP 基础

| 名词 | 是什么 |
|---|---|
| 公网 IP | 你的网络在互联网上的地址，网站和平台看到的就是它 |
| 运营商（ISP） | 给你提供网络的公司，比如家庭宽带、手机网络、云服务商 |
| ASN | 自治系统号，标识一段 IP 属于哪个网络运营方。平台看 ASN 就能大致知道这个 IP 来自家庭宽带、手机网络还是机房 |
| 地理位置 | 根据 IP 数据库推断的大概位置，不一定精确 |
| 出口 IP | 公司或家里所有设备上网时共用的那个公网 IP |

### 常见 IP 类型对比

| 类型 | 从哪来 | 稳定性 | 平台通常怎么看 | 主要风险 |
|---|---|---|---|---|
| 住宅 IP | 家庭宽带运营商分配给普通家庭 | 中，可能定期变化 | 像普通用户，信任度较高 | 市面上卖的「住宅代理」来源复杂，很多是共享、轮换的，质量和来源合规性参差不齐 |
| 机房 / 数据中心 IP | 云服务商、托管机房 | 高，固定 | 一看 ASN 就知道是机房。用来托管网站、服务器发信是正常的；用来登录个人或商家账号容易被额外审查 | 很多机房 IP 段有滥用历史，可能在黑名单里 |
| 移动 IP | 手机运营商网络 | 低，经常变 | 平台知道很多人共用一个移动出口 IP，相对宽容 | IP 频繁变化，不适合做固定办公网络 |
| 静态住宅 IP（ISP IP） | 注册在宽带运营商名下，但放在机房里固定出租 | 高，固定 | 看起来像住宅，但识别手段在不断进步 | 供应商质量差异大，被识别后信任度下降 |
| 共享代理 / VPN 节点（俗称「机场」） | 一个节点被大量用户共用 | 低，频繁切换 | 高风险：多人共用、滥用多、经常被标记为代理 | 最容易触发异常登录验证和封号，见第 3 部分 |
| 企业跨境专线 | 有资质的基础电信运营商为外贸等企业提供的跨境网络 | 高，固定 | 和普通企业网络一样，稳定一致 | 有成本，需要以企业身份办理 |

## 2. 平台风控怎么看 IP

平台风控要判断的是：**这是不是账号的真实主人，是不是正常使用，有没有被盗或被批量操作。** IP 只是其中一个信号，平台会综合看：

| 信号 | 平台在判断什么 |
|---|---|
| IP 信誉 | 这个 IP 有没有上黑名单、有没有大量注册或刷量的历史 |
| IP 类型 | 来自家庭、手机、机房，还是已知的代理和 VPN |
| 共用程度 | 有多少账号从这个 IP 登录 |
| 位置一致性 | 和这个账号平时的登录地是否一致；短时间内从相隔很远的地方登录，会被当成异常 |
| 设备一致性 | 是不是常用的电脑、手机和浏览器 |
| 资料一致性 | 企业名称、地址、网站、付款方式是否前后一致 |
| 行为模式 | 新号注册后马上大量加好友、发私信、改资料、上广告，像机器人 |

**最容易触发问题的情况：**
- 短时间内频繁换 IP 或换节点
- 很多账号挤在同一个 IP 或同一台设备上
- 新账号一注册就做大量操作
- 账号资料、付款方式和登录环境对不上

**结论：稳定和一致，比「看起来像在某个地方」重要得多。**

## 3. 为什么共享「机场」节点风险高

- **一个 IP 被成千上万人共用**：平台看到大量不相关的账号从同一个 IP 登录，信任度会很低
- **滥用历史多**：有人用同一节点刷量、注册小号、发垃圾邮件，整个 IP 都会被标记
- **频繁切换节点**：今天在洛杉矶、明天在新加坡，看起来就像账号被盗
- **跨境合规问题**：在中国大陆，跨境联网应通过依法设立的国际通信出入口；未经电信主管部门批准的翻墙服务存在法律风险。外贸企业的合规做法是向有资质的基础电信运营商申请跨境专线等服务，具体以当地主管部门和运营商的最新规定为准

**用于运营商业账号时，不要用共享节点。**
