
# Creative Testing

## Goal

A repeatable testing system: every week new creatives go in, decisions are made by rules, and learnings are recorded so the next round is smarter.

## Before you start: gather context

- Platform(s), weekly budget, target CPA or ROAS
- How many new creatives can be produced per week
- Past winners and losers, if any

## What to test, in order of impact

1. **Concept / angle**: the core idea (pain vs social proof vs demo)
2. **Hook**: the first line or first 3 seconds
3. **Format**: UGC video, static, carousel, founder video
4. **Body and CTA**
5. **Copy and headline**
Test big things first. Changing a button color will not save a weak concept.

## Testing setup

- Write a hypothesis for every test: "Leading with the 30-day guarantee will raise CTR because the main objection is risk."
- Change one main variable per test so the result is readable.
- Keep testing separate from scaling (on Meta: a testing campaign; on TikTok: a testing ad group) so tests get spend.
- Launch in batches (for example 3–6 new ads per week) rather than one at a time.

## Metrics hierarchy

| Stage | Metric | Tells you |
|---|---|---|
| Stop | Hook rate (3-second views ÷ impressions), thumb-stop | Does the opening work? |
| Hold | Hold rate, average watch time | Is the middle interesting? |
| Click | Link CTR, CPC | Does it create intent? |
| Convert | CVR, CPA, ROAS | Does it make money? |

Read top-down: fix the earliest stage that fails.

## Kill / keep / iterate rules (adjust to the account)

- **Kill early** if, after meaningful impressions, hook rate and CTR are clearly below account average.
- **Judge on CPA** once an ad has spent around 1–2× target CPA.
- **Keep** if CPA is at or below target; move it to scaling.
- **Iterate** if early metrics are strong but CPA is slightly high: new hooks, new CTA, different landing page.
- Do not judge on a single day; weekday and auction swings are normal.

## Iterating on winners

When a concept wins, make variations before it fatigues: five new hooks, a different creator, a shorter cut, a static version, a new offer framing.

## Creative log

Record every test: date, ID, concept, hook, format, hypothesis, spend, hook rate, CTR, CPA, decision, learning. Patterns across many tests are worth more than any single winner.

## Output format

1. Test plan table: ID, hypothesis, variable, creative description, budget, success metric
2. Kill / keep / iterate thresholds using the user's numbers
3. Creative log template
4. Next round recommendations based on results (if provided)
