# Instagram 运营

> For agents: use for organic Instagram (Reels, carousels, Stories, DMs). For Meta ads see `paid-ads` → `references/meta-ads.md`. Features and ranking guidance change often; tell the user to confirm current rules in the app.

## 适合谁

视觉好看、偏生活方式的品类（家居、服饰、美妆、宠物、食品），以及想建立品牌形象、做私信成交的卖家。Instagram 和 Facebook 同属 Meta，广告账户、商品目录、私信可以打通。

## 账号设置

- **账号类型**：切换为专业账号（Professional account），选「商家」（Business）。可以看数据、加联系按钮、关联 Facebook 主页和商品目录
- **用户名和名称**：用户名用品牌名；「名称」栏可以加关键词，比如「CoreSeat | Seat Cushions」，方便被搜到
- **简介**：你是谁 + 能帮用户什么 + 一个行动号召，可以加一个品牌话题标签
- **链接**：主页链接放独立站或落地页，加 UTM
- **精选快拍（Highlights）**：做成固定栏目：评价、使用方法、常见问题、配送和退货
- **商品功能**：符合条件的话开启 Instagram 购物，让帖子能标记商品（以当前地区和资格为准）

## 内容形式

| 形式 | 作用 | 要点 |
|---|---|---|
| Reels（短视频） | 获取新粉丝的主力 | 竖屏 9:16，前 3 秒抓人，字幕要有 |
| 轮播图（Carousel） | 收藏率高，适合干货 | 第一张是标题和钩子，最后一张放行动号召 |
| 单图 | 品牌形象、新品发布 | 画面干净，配一句有观点的文案 |
| 快拍（Stories） | 维护老粉、引导私信 | 投票、提问、倒计时贴纸，多做互动 |
| 私信（DM） | 成交和客服 | 设置常见问题自动回复，见 `conversational-sales` |
| 直播 | 新品、答疑 | 前期频率低一点也可以 |

## 推荐机制（简化理解）

Instagram 官方多次提到，分发会看这些信号：
- **观看时长**：Reels 有没有被看完
- **分享**：尤其是被用户私信分享给朋友，对触达新用户很重要
- **点赞、评论、收藏**
- **原创**：直接搬运、带其他平台水印的内容，推荐会受影响

所以：**做别人愿意转发给朋友的内容**，用原始素材剪辑，不要直接上传带 TikTok 水印的视频。

## 几个实用功能

- **试用版 Reels（Trial Reels）**：先只推给非粉丝，表现好再推给粉丝，适合测试新方向（以当前是否可用为准）
- **合作帖（Collab）**：和达人或合作品牌共同发布，同时出现在两个账号
- **关键词搜索**：简介、文案、屏幕文字都写上关键词，比堆话题标签更有用
- **话题标签**：3 到 5 个相关的就够

## 发布节奏

- Reels：每周 3 到 5 条（可以和 TikTok、Shorts 共用素材）
- 轮播图：每周 1 到 2 条
- 快拍：尽量每天几条，保持存在感
- 发布后回复评论和私信

## 内容配比

用一个简单的规则：**大部分内容给价值，少部分卖货**。
- 干货和教程：怎么用、怎么选、常见错误
- 用户和评价：顾客照片、UGC、真实反馈
- 幕后和品牌：做产品的过程、团队、价值观
- 产品和促销：新品、活动、限时（只用真实的截止时间）

## 看哪些数据

| 指标 | 说明 |
|---|---|
| 触达非粉丝的比例 | 内容有没有被推给新人 |
| Reels 平均观看时长 | 留不留得住人 |
| 分享、收藏 | 内容有没有价值 |
| 主页访问、链接点击 | 能不能带来生意 |
| 私信数量 | 私域成交的入口 |
| 粉丝增长 | 结果指标，不要只盯这个 |

## 和广告的衔接

- 表现好的帖子可以直接推广，或用「合作广告」（Partnership ads）投放达人内容
- Instagram 私信可以接点击即聊广告，配合 `conversational-sales` 的话术

## 新手常见错误

- 只发产品图，像商品目录
- 把 TikTok 视频带水印直接搬过来
- 简介不写清楚做什么、没有链接
- 只发帖不回私信，错过成交
- 买粉、用互动群刷数据：违反平台规则，还会让数据失真
